# QCustomer-Relationship-Management
QCRM 不是一套通用的「通讯录式 CRM」，而是一套围绕大客户项目赢单的关系作战系统。它把散落在 Excel、PPT、个人笔记里的客户情报，结构化为可查询、可关联、可计算的经营数据，并通过 C74111 诊断模型把「凭感觉判断项目能不能赢」变成「用分数和区间客观评估」。  系统覆盖 16 个业务实体，形成「客户 → 项目 → 人员 → 关系/画像/诊断」的完整数据网络，通过系统网络组织架构的模式直观展现业务面关系。
